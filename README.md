## 👋 About

**SchifanoIA** is my blog about running AI *at home*: no cloud subscriptions, no data leaving the house — just an old PC, two consumer GPUs and a lot of tinkering.

This repository collects the scripts, configuration files and small tools I actually use in my homelab. Everything here has been tested on my own hardware, and I'm sharing it in the hope it saves someone else a few evenings of trial and error.

> ⚠️ These are homelab files, not production-grade software. Read them, understand them, adapt them to your setup.
